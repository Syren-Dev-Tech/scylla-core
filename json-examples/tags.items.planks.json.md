# tags items planks JSON Example

## File Structure

- Type: data pack
- Path: src/main/resources/data/minecraft/tags/item/planks.json
- Namespace: minecraft (vanilla tag extension)

## Example JSON

```json
{
  "replace": false,
  "values": [
    "scylla:maple_planks",
    "scylla:cedar_planks"
  ]
}
```

## What This Defines

Adds modded plank items to vanilla plank recipes and systems.
Tag files are one of the most important cross-mod compatibility mechanisms.
