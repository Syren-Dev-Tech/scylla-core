# tags items pickaxes JSON Example

## File Structure

- Type: data pack
- Path: src/main/resources/data/minecraft/tags/item/pickaxes.json
- Namespace: minecraft (vanilla tag extension)

## Example JSON

```json
{
  "replace": false,
  "values": [
    "scylla:ruby_pickaxe",
    "scylla:obsidian_pickaxe"
  ]
}
```

## What This Defines

Adds your custom pickaxe items to the vanilla `minecraft:pickaxes` tag.
Tagging tools improves compatibility with recipes, datapacks, and tool-aware integrations.
