# lang en_us JSON Example

## File Structure

- Type: resources
- Path: src/main/resources/assets/scylla/lang/en_us.json
- Namespace: scylla

## Example JSON

```json
{
  "item.scylla.ruby": "Ruby",
  "block.scylla.ruby_ore": "Ruby Ore",
  "item.scylla.ruby_sword": "Ruby Sword",
  "entity.scylla.drake": "Drake",
```

## What This Defines

Language key translations for UI text.
Every displayable registry object and subtitle should have an entry.
