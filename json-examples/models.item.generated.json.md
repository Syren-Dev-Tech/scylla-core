# models item generated JSON Example

## File Structure

- Type: resources
- Path: src/main/resources/assets/scylla/models/item/ruby.json
- Namespace: scylla

## Example JSON

```json
{
  "parent": "minecraft:item/generated",
  "textures": {
    "layer0": "scylla:item/ruby"
  }
}
```

## What This Defines

A flat item sprite rendered in GUI and held form.
Use this for most non-tool items such as ingots, gems, and food ingredients.
