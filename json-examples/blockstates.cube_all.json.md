# blockstates cube_all JSON Example

## File Structure

- Type: resources
- Path: src/main/resources/assets/scylla/blockstates/basalt_bricks.json
- Namespace: scylla

## Example JSON

```json
{
  "variants": {
    "": {
      "model": "scylla:block/basalt_bricks"
    }
  }
}
```

## What This Defines

This is the simplest blockstate mapping. Every state of the block points to one model.
Use this for blocks without properties (for example simple decorative blocks).
