# pack mcmeta JSON Example

## File Structure

- Type: root metadata
- Path: src/main/resources/pack.mcmeta

## Example JSON

```json
{
  "pack": {
    "pack_format": 61,
    "description": "Scylla resources and data"
  }
}
```

## What This Defines

The pack metadata for the built-in resource/data pack shipped by the mod.
The pack format must match your target Minecraft version.
