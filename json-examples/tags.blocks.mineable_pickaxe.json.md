# tags blocks mineable_pickaxe JSON Example

## File Structure

- Type: data pack
- Path: src/main/resources/data/minecraft/tags/block/mineable/pickaxe.json
- Namespace: minecraft (vanilla tag extension)

## Example JSON

```json
{
  "replace": false,
  "values": [
    "scylla:ruby_ore",
    "scylla:ruby_block",
    "scylla:basalt_bricks"
  ]
}
```

## What This Defines

Adds your blocks to the vanilla pickaxe-mineable tag.
This controls effective tool behavior and interacts with mining speed and loot logic.
