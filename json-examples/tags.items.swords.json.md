# tags items swords JSON Example

## File Structure

- Type: data pack
- Path: src/main/resources/data/minecraft/tags/item/swords.json
- Namespace: minecraft (vanilla tag extension)

## Example JSON

```json
{
  "replace": false,
  "values": [
    "scylla:ruby_sword",
    "scylla:obsidian_sabre"
  ]
}
```

## What This Defines

Adds your custom sword items to the vanilla `minecraft:swords` tag.
This helps vanilla and modded systems that query sword membership behave correctly.
